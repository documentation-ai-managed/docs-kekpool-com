## Quick Start

1. Go to `https://kekpool.com`.
2. Choose a supported coin (e.g., Kaspa).
3. Download mining software (e.g., lolMiner).
4. Enter KEKPOOL's mining address (listed on the site).
5. Set your wallet address as the user.
6. Start mining!

## Example lolMiner Command

````bash
lolMiner -a KASPA -p stratum+tcp://kas.kekpool.com:port -u YOUR_WALLET_ADDRESS
````

No registration needed. Your address is your account.
